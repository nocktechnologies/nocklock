- 2026-11-08: contract test follow-up. - 2026-11-08: 1.0 bar 4 audit. `docs/reference/cli.md` now matches the code, and `internal/cli/contract_test.go` pins it (goldens in `internal/cli/testdata/contract/`; regenerate with `-update-contract-golden` after updating the page). The audit found that most `wrap` startup refusals (invalid config, Landlock or filesystem fence unenforceable, audit database unopenable, netns off Linux) exit 1 through `root.go`, not 2; only the refusals the page lists exit 2. The page and the invariants now say so; no behavior changed. Hidden commands and wrap's hand-parsed flags are pinned too, since cobra cannot list wrap's flags (`DisableFlagParsing`). The config golden lists each table as `[table]` or `[[table]]`, so changing one into the other fails it. The egress-level and run-state checks scan package-level source constants and resolve their type the way Go does for the forms in use: declared (`x T = "v"`, also through a type alias), converted (`x = T("v")`, however parenthesized), inferred from another constant (`x = y`) or repeated in a const block; a form the scan cannot read, a name a build-tagged file pair both declare, or a cycle is an error, so a new value fails until the test list and the page change with it. Constants inside function bodies are not scanned. The command check parses the page's Commands table: each command, cobra's `help` and `completion` included, must be named exactly, and each visible flag and shorthand must appear in that command's own row. Two commands sharing a row (`anchor emit`, `anchor push`) share its flag list, so one command's flag can satisfy the other's; split the row if that matters. The documented contract keeps `wrap` passing child codes through, with stderr and the `session_end` row telling them apart from NockLock's; whether 1.0 keeps that or reserves codes is still open (`docs/ROADMAP.md` bar 4) (decided 2026-11-11: pass-through kept, #311). A child that cannot be resolved or launched after the run starts writes `session_end` `exit_code=1` alone and prints the bare error; `session_close` `end=refused` marks the unresolved command and the unbuildable netns request, while an exec failure closes `end=child_exit` like a child exiting 1. The command golden holds on macOS too: every `rootCmd.AddCommand` call sits in an untagged file (`internal/cli/wrap.go`, `internal/cli/probe.go`, `internal/cli/netns_helper.go` and the rest), so darwin registers the same tree, and `GOOS=darwin GOARCH=arm64 go vet ./...` compiles the contract tests; the macOS runner proves it once the PR is ready. The `network.require_durable_audit` with netns error suggests `--net-fence=proxy`, which the flag parser rejects; the message needs a fix in a behavior change.

## What bit us

- 2026-10-26: config-digest tests use the checkout directory in filesystem grants. On macOS, a checkout under the protected home .codex directory correctly triggers credential-overlap refusal. A checkout under /tmp also puts the preset fixtures' fake homes beneath a default allow and triggers the same protection. Run those tests from a disposable source copy in an ordinary development directory; do not relax the policy to accommodate the checkout.

- 2026-10-23: the macOS credential proof (`scripts/test-credential-denies.py`) still set only `project.runtime` and wrapped `/bin/sh`, so it failed once that key stopped unlocking a login store. It now wraps with `--profile <agent>` for the own-store read and asserts `project.runtime` alone keeps the store denied.

- 2026-10-22: mandatory credential denies make a fake home beneath /tmp incompatible with the default /tmp allow, and root=/ is now refused even in network-only fixtures. CLI fixtures keep fake homes beside the package and network proofs grant their temporary project plus runtime paths.

- 2026-10-17, on a dev host: `go test ./...` failed in `internal/logging` under umask 002. The failure in `TestWrapComposedDefaultEgressAudit` was suspected to involve a week-old installed binary used by the egress helper; that host cause was not reverified. Both conditions are now `AGENTS.md` gotchas.
